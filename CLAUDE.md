## 🎨 UI/UX & Design Guidelines

- **Styling**: Prioritize modern, clean, high-contrast visual design. Use structured CSS design tokens (colors, typography, spacing).
- **Theme**: Support modern UI paradigms including responsive layouts, dark mode options, subtle hover state micro-animations, and clean typography.
- **Components**: Maintain modular, reusable components with clear separation of concerns.

---

## 📜 Code Style & Quality Rules

1. **Clean Code**:
   - Write self-documenting code with clear variable and function names.
   - Use TypeScript type definitions where applicable.
2. **Modularity**:
   - Keep files focused on a single responsibility.
3. **Environment Security**:
   - Never commit sensitive secrets, private API keys, or credentials to version control.
   - Always reference environment variables via `.env`.
4. **Git Practices**:
   - Write clear, descriptive commit messages summarizing functional changes.
